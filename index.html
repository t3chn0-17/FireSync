FireSync documentation

FireSync compares NASA FIRMS active-fire observations from MODIS and VIIRS over Egypt, platform by platform, without merging them. Built for the NASA Space Apps Challenge 2026: Harmonization of MODIS and VIIRS Hot Spots.

Overview

The prototype turns four FIRMS CSV downloads (1,282 observations, 449 one-kilometre grid cells) into aggregated datasets and a read-only REST API for a MapLibre dashboard.

Keeps platforms apart

Every aggregate carries sensor and platform. FRP is never summed across sensors.

Real data only

The API serves processed FIRMS records. Nothing is mocked or invented.

Simple stack

Python, pandas, PyProj and FastAPI. CSV and JSON files, no database.

Quick start

Requires Python 3.10 or newer. Put the four FIRMS CSV files in data/.

pip install -r requirements.txt
cp .env.example .env
python pipeline.py        # validate + assign 1 km grid
python harmonization.py   # daily, platform and spatial aggregates
python api.py             # serves on 0.0.0.0:8000
python test_api.py        # optional: run the test suite

Open http://<your-lan-ip>:8000/docs for the interactive API explorer. Other devices must use the LAN IP, not localhost.

Architecture

data/*.csv→pipeline.py→normalized_valid.csv→harmonization.py→output/*.csv, *.json→api.py→MapLibre frontend

pipeline.py loads, normalizes and validates records, then assigns grid cells with EPSG:6933. harmonization.py builds aggregates and checks that they add up to the source count. api.py loads the outputs at startup and serves them as JSON and GeoJSON.

FileRole
pipeline.pyLoad, normalize, validate, grid assignment
harmonization.pyDaily harmonization, statistics, spatial summary, integrity report
api.pyFastAPI server with CORS and filters
test_api.pyEndpoint, filter and GeoJSON coordinate tests

API reference

All endpoints are GET unless noted. Filters: start_date, end_date (YYYY-MM-DD), sensor, platform, satellite, min_frp, max_frp, limit. Several values can be comma-separated.

EndpointReturns
GET/healthAPI status and whether processed data is loaded
GET/api/overviewTotals, sensors, platforms, date range, valid and rejected counts
GET/api/observationsPaginated observations (limit, offset)
GET/api/observations/{id}One observation
GET/api/hotspots/geojsonGeoJSON FeatureCollection, WGS84 [lon, lat]
GET/api/harmonizationDaily cell-date-platform rows
GET/api/statisticsChart-ready platform and sensor statistics
GET/api/grid/{grid_id}One cell: platform stats, daily rows, observations

Frontend integration

Set the API base URL to the backend machine’s LAN IP. CORS is open by default; restrict it with FIRESYNC_CORS_ORIGINS.

# .env (backend)
FIRESYNC_HOST=0.0.0.0
FIRESYNC_PORT=8000
FIRESYNC_CORS_ORIGINS=*

# frontend, e.g. Vite
VITE_API_BASE_URL=http://192.168.1.50:8000

Add the hotspots to a MapLibre map and colour them by platform:

map.on('load', async () => {
  const url = `${API}/api/hotspots/geojson?sensor=VIIRS`;
  map.addSource('hotspots', { type: 'geojson', data: url });
  map.addLayer({
    id: 'hotspots', type: 'circle', source: 'hotspots',
    paint: {
      'circle-radius': 5,
      'circle-color': ['match', ['get', 'platform'],
        'MODIS', '#d9482b', 'VIIRS_SNPP', '#1b998b',
        'VIIRS_NOAA20', '#2a7fb8', 'VIIRS_NOAA21', '#6b5bb5', '#888']
    }
  });
});

Scientific notes

Read results with care.
  • Detections in one grid cell on one date are not necessarily the same fire. Unique cells are not unique fires.
  • MODIS and VIIRS differ in resolution and sensitivity. FRP is never summed or merged across sensors.
  • Confidence is kept as in the source: MODIS is numeric (0–100), VIIRS is categorical (l, n, h). The two are not comparable.
  • More observations from a platform do not show it is a better sensor.

Limitations

  • Covers Egypt, 1–9 November 2026, from four FIRMS NRT files. It does not predict fires or claim to detect every fire.
  • Data is loaded at startup. After re-running the pipeline, call POST /api/reload or restart the server.
  • FireSync is a prototype and has not been validated or endorsed by NASA.
